# 3.0.4 更新说明

## 排版

- 修复两端对齐重排中断点抖动：换行留在行尾的空格不再被临时改成 0 宽，避免下一行首字被吸上来又推回去。
- 两端对齐在整像素余量刚好填满栏宽时保留 1px 安全余量，避免 Android 断行器为了重排优化把最后一个字挪到下一行。
- 真机复量：28 页不变，换行点与修复前基线 0 差异；固定分母下右边界短行从 36 行降到 27 行；Word 边缘对齐抽样中 79/88 行在右边距 1px 内，0 行短出 8px 以上，0 行比 Word 自身更越过右边距。
- 分页仍有已量化差异：207 个对齐段落中 193 个页归属一致，14 个提前一页，页归属一致率 93.2%；这一项仍未达到仓库 10 段的验收线，后续继续追上下标与西文宽度造成的页前行数差。

## 查重

- 自建库超过一个探测批次后，候选检索采用 Noplag 式“稀有指纹优先”排序，减少高频术语带来的无效倒排扫描；最终重复判定、重复率和高亮区间仍由原有引擎完成。
- 公开检索候选可保存进自建库：有摘要的按摘要层保存，没摘要的按仅题录保存；只入库题名、作者、年份和摘要，不入库 URL、HTML 或原始响应。
- AIGC 检测保持离线与未标定状态，界面不显示百分比；降重词表继续使用已并入的 aigc-reduce MIT 规则。

## 测试

- 宿主回归 52 个套件全部通过，包括新增的 Noplag 候选探针与公开候选入库回归。
- 真机排版捕获通过：28 页、14,460 字、换行点 0 差异。
- 查重底线审计：18/19 通过，0 个致命失败，1 个已记录的轻改写盲区仍按原口径报告。
